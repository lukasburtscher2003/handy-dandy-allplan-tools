# HJ Tools – Allplan PythonParts & VisualScripts

Eine Sammlung selbst entwickelter Erweiterungen für Allplan zur Automatisierung und Vereinfachung von Planungsprozessen.

## Enthaltene Tools

### HJ Dev-Tutorial
Ein Beispiel- und Lernwerkzeug für die Entwicklung eigener PythonParts und VisualScripts in Allplan. Es dient als Grundlage für die Entwicklung weiterer individueller Erweiterungen.

### HJ UrbGEN
Ein parametrisches Werkzeug zur automatisierten Erstellung und Untersuchung von Bebauungsvarianten unter Berücksichtigung städtebaulicher Kennzahlen, Grundstücksgrenzen und Gebäudeabstände.

## Kompatibilität

Entwickelt für Allplan 2027. Die Kompatibilität mit früheren Allplan-Versionen ist derzeit nicht gewährleistet.

## Entwicklung

Die Tools werden kontinuierlich weiterentwickelt. Fehlerberichte, Anregungen und Verbesserungsvorschläge sind willkommen.

## Installation
1. Die aktuelle .allep-Datei unter Releases herunterladen.

2. Die Datei per Drag-and-Drop in Allplan öffnen und den Installationsanweisungen folgen.

3. Allplan neu starten.

4. Die installierten Tools stehen anschließend in Allplan im Reiter Plug-Ins zur Verfügung.

5. Für Updates einfach die neueste .allep-Datei installieren.

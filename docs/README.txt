HJ SUPPORT – Anwenderdokumentation

1. ZIP vollständig entpacken.
2. index.html im Browser öffnen. Kein Server und keine Installation erforderlich.
3. Den Ordner inklusive assets zusammenlassen. Alle Links sind relativ.

Erweiterung: Eine neue HTML-Seite auf Basis einer vorhandenen Seite anlegen.
Ein neues Werkzeug nur im Array tools in assets/support.js ergänzen.
Navigation, Werkzeugkachel, Suchfunktion und Feedbackauswahl werden daraus
automatisch erstellt. Header und Footer werden ebenfalls zentral erzeugt.
Das gemeinsame Design liegt unter assets/style.css. JavaScript muss aktiviert
sein; die Anleitungen selbst bleiben statische HTML-Inhalte.

Für GitHub Pages: Inhalt dieses Ordners in die bestehende Dokumentationsablage
kopieren, nicht in das ALLEP-Paket. Änderungen vor dem Commit vergleichen.
Entwicklerhilfe und interne Verzeichnisse bleiben privat.
Die private Entwicklerhilfe (.dev) ist nicht Teil dieses öffentlichen Pakets.
